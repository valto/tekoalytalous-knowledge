# Metatietomallit

Tekoälytalous.fi käyttää Open Knowledge Format 0.2 -rakennetta ja sen sallimia tuottajakohtaisia lisäkenttiä.

- [concept.schema.json](concept.schema.json) kuvaa repositoryn varsinaisten tietueiden vähimmäisrakenteen.
- Open Knowledge Format määrittelee yleisen tietopaketti- ja käsiterakenteen.
- Tekoälytalous.fi:n lisäkentät säilyttävät muun muassa toimituksellisen tilan, näyttötason, tarkistusajan, maantieteen ja falsifiointiehdot.

JSON Schema toimii julkisena sopimuksena ja työkalujen lähtökohtana. Repositoryn oma tarkistus toteuttaa lisäksi tiedostojen väliset säännöt, kuten yksilölliset tunnisteet ja toimivat sisäiset linkit.
