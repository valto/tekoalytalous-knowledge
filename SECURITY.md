# Turvallisuusilmoitukset

Älä julkaise mahdollista tietoturvaongelmaa, henkilötietoa, tunnusta tai muuta arkaluonteista aineistoa julkisena GitHub-kysymyksenä.

Käytä GitHubin yksityistä haavoittuvuusilmoitusta, jos se on käytettävissä repositoryn **Security**-välilehdellä. Muussa tapauksessa ota yhteyttä Tekoälytalous.fi-sivuston yhteydenottokanavan kautta ja kerro vain, että kyse on tietoturvailmoituksesta. Arkaluonteiset yksityiskohdat sovitaan erikseen turvallista kanavaa varten.

Tavalliset sisältövirheet ja rikkinäiset julkiset linkit voi ilmoittaa julkisella korjauslomakkeella.
